Project Proposal

1. Project Title
Design Resource Library

2. Project Description
My project is going to be a website where designers can organize useful design
resources into their own libraries. Users will be able to create libraries for
different topics, such as fonts, colours, web design, or inspiration.
Each resource will have a name, link, rating, and description. Users will also be
able to choose if their library is public or private. Public libraries can be viewed
by other users through a Discover section, where users can find different resource
collections. Users will also be able to upvote a library if they find it helpful.
The main purpose of the website is to make it easier to keep design resources
organized and also make it easier to find resources that other designers have
collected.

3. Motivation
I chose this project because I am interested in graphic design and web development,
and I often find different websites and resources that can be useful for design
projects. I wanted to make a website where these resources could be organized
instead of having them saved in different places.
I also wanted to make something that I could actually see myself using. The public
library feature would also make it useful for other designers because they could
share resources they find helpful.
This project will also give me a chance to learn more about PHP and databases. I
have worked with some basic PHP already, but I want to get more comfortable with
using PHP to make a website that actually stores and changes information.

4. Key Features
Create an account
Log in and log out
Create a resource library
Edit and delete libraries
Make libraries public or private
Add resources to a library
Edit and delete resources
Give resources a rating from 1–5
Add a name, link, and description to resources
Browse public libraries in a Discover section
View resources inside public libraries
Upvote public libraries
Sort libraries by the number of upvotes
View and manage personal libraries
Keep private libraries hidden from other users

5. Technical Approach
I plan to use PHP, MySQL, HTML, CSS, and some JavaScript to build the project.
PHP will be used to handle things like forms, logging in, creating and editing
libraries and resources, and getting information from the database. MySQL will store
the users, libraries, resources, and upvotes.
I plan to have different tables for users, libraries, resources, and votes. The
tables will be connected so that each library belongs to a user and each resource
belongs to a library.
I will use PHP sessions to keep track of which user is logged in. This will also
help with making sure users can only edit their own libraries and that private
libraries cannot be viewed by other users.
I will keep the front end and back end organized into separate files. The website
will first be developed and tested on localhost and then uploaded to a cPanel
website.

6. Project Scope
The main goal is to create a working website where users can make accounts, create
their own resource libraries, add resources, and choose whether their libraries are
public or private.
The main features I plan to complete are user login, library and resource CRUD,
database storage, public and private libraries, the Discover section, and library
upvotes.
If I have enough time, I may add extra features such as better searching and
filtering for public libraries. These features are optional and will depend on how
much time I have after completing the main parts of the project.
One of the main challenges I expect will be connecting the different database tables
and making sure the correct user has access to the correct information. I also
expect that learning how to use PHP sessions and working with a database will be
some of the harder parts of the project. I think the project will be challenging for
me, but still realistic to complete during the semester.
